# Write Docs Skill

- **Purpose**: To provide a standard guide for polishing technical documentation, to be used when users request writing, polishing, or supplementing article content.
- **Scope**: This skill can be applied to various types of technical documentation, including but not limited to API documentation, user manuals, and technical articles.
- **Key Principles**:
    1. **Relevance**: Review the article content and the given context, and write within the framework of the context.
    2. **Consistency**: Maintain a uniform tone throughout the text, ensure continuous content, consistent style, and unified formatting.
    3. **Conciseness**: Ensure the content is clear and easy to understand, tailored to the target audience, with prominent keywords and key points, logical clarity, and well-structured hierarchy. Convey all necessary information while keeping the content concise.
    4. **Accuracy**: Verify the accuracy and timeliness of all technical information. Cite sources for any data or materials used.
    5. **Appeal**: Use vivid language and examples, and make good use of illustrations, metaphors, and analogies to explain complex concepts, making the content more engaging and easier to understand.
    6. **Readability**: Organize content with clear headings, subheadings, paragraphs, and lists to enhance readability. Use appropriate fonts, colors, and charts to improve visual appeal.
